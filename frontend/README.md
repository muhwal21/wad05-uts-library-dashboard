# Frontend

Antarmuka dashboard perpustakaan menggunakan Vue 3 dan Vite.

## Menjalankan

```sh
npm install
npm run dev
```

Pastikan backend FastAPI berjalan di `http://127.0.0.1:8000`. Untuk mengganti alamat API, atur `VITE_API_BASE_URL` sebelum menjalankan frontend.

## Build

```sh
npm run build
```
